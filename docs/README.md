# Documentation

`docs/` contains current product, architecture, contract, deployment and
developer documentation.

- `contracts/`: stable cross-domain contracts.
- `adr/`: architecture decisions.
- `roadmap/`: approved forward-looking work.
- `v1/`: preserved V1 compatibility and migration material.

Historical implementation evidence is kept in `outputs/`; it is not the source
of current behavior. Executable project templates remain in `templates/`.
